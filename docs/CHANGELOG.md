# Changelog

## v1.0.0 — Release Candidate
- Consolidated v0.1–v0.9 functionality into the release candidate.
- Refreshed release documentation and verification boundary.


## 0.7.0

- Added versioned `/api/v1` endpoints.
- Added API key abilities and ability middleware.
- Added per-key API rate limiting foundation.
- Added Idempotency-Key persistence and replay protection.
- Added API health endpoint with database status.
- Added products, inventory, and report-summary read APIs.
- Added load-balancing strategy abstractions: round robin, weighted round robin, least connections.
- Consolidated continuation/security/scalability documentation.

## 0.6.0

- Added reports and analytics.
- Added master documentation set.


## v0.9 — Advanced Operations

- Added customer directory and customer-linked sales.
- Added transactional sales returns/refunds with restock or damaged disposition.
- Added expense categories and expense recording.
- Added return/expense operational navigation and permissions.
- Extended reports with returns, expenses, and active customer indicators.
## v1.0.0 UI refresh

- Reworked the shared application shell into a dark operations SaaS interface.
- Added collapsible desktop sidebar and mobile off-canvas navigation.
- Added InventoryOS logo/brand treatment and consistent navigation icons.
- Rebuilt the dashboard around live sales, purchasing, inventory, warehouse, low-stock and movement data.
- Added date-range filtering for dashboard operational metrics.
- Added responsive sales-performance, business-pulse, top-products, inventory-health and movement panels.
- Added local `public/logo.svg` and `docs/UI_SYSTEM.md`.
